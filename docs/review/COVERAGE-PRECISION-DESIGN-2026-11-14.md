# Coverage precision follow-up

Personal project; not legal or regulatory advice.

The eight-question live run exposed two distinct causes: the cure guard only checked conditions
when the model mentioned them; broad peer availability was treated as a mandatory research task.
The user requested implementation of the follow-up and another focused check.

Design and execution decisions:

1. Recognise an explicit source link from a matched time rule to an immediately following
   condition list referring to the previous paragraph's period. Keep document/block identity,
   whole-window delivery and all caller filters. Probe at most four diverse document anchors.
   Test uncited conditions, long explanatory tails, excluded scenarios and split windows.
2. Keep broad lexical peers available to pre-draft expansion, but require an explicit child-list
   relationship or a directly requested facet before unread peers force more research.
   Do not clear a genuine model-declared unresolved requirement to make a flag disappear.
3. Share the existing two-call single-pass limit between format repair and a focused rewrite
   of omitted facts already fully delivered. Only independent structural omission signals can
   trigger that rewrite; unread evidence still requires the normal bounded fallback. Recheck
   the second draft and retain any remaining gap. API/Codex and post-agent checks share the guard.
4. Add failing regressions, run focused tests and disposable SQL checks, then the full suite.
   Replay actual raw provider drafts from the prior run rather than already-mutated records.
5. Evaluate only the two remaining problem cases, with fresh routes, answers, grade artifacts and
   a 750,000-token aggregate reserve (375,000 per question, including all retries/fallback/grade).
   This is below the project's 1M approval threshold. Preserve the previous full and focused runs.
   Stop on quota rejection, unknown usage or the request reserve; do not alter code mid-run.

No paid judge is added to ordinary product answers. These remain finite structural/lexical
signals, not proof of complete coverage or legal entailment. Record both recovery and cost.
